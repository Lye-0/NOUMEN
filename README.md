# NOUMEN — 深宙観測博物館

**未知は、静かに存在する。**

五つの架空の惑星を鑑賞する、小さな3D宇宙博物館です。俯瞰から天体を選び、近づき、その不可解な観測記録を読む作品です。

## 起動

### GitHub Pages

1. このフォルダの**中身**をリポジトリのルートに配置します。`index.html` が直下に来るようにしてください。
2. GitHub の **Settings → Pages → Build and deployment → Source** を **Deploy from a branch** にします。
3. **Branch: main / Folder: / (root)** を選び、Save を押します。

ビルド、npm install、APIキー、環境変数は不要です。HTML / CSS / JavaScript と同梱画像だけで構成されているため、独自の `.github/workflows` は含めていません。`.nojekyll` は空ファイルのまま残してください。相対パスなので、`https://ユーザー名.github.io/リポジトリ名/` のようなサブディレクトリ公開にも対応します。

GitHub公式の設定手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

### ローカルで確認する

Node.js がある場合、フォルダを開いて次を実行します。追加パッケージは不要です。

```powershell
node tools/serve.cjs
```

ブラウザで `http://127.0.0.1:8000` を開きます。8000番が使用中なら、`node tools/serve.cjs 8001` で変更できます。終了は Ctrl+C です。

`index.html` をダブルクリックするだけの `file://` では、ブラウザのローカル画像保護によって3Dテクスチャを読み込めない場合があります。その場合は静止画展示に切り替わります。3D版はHTTPサーバー経由で開いてください。

## 収蔵天体

| 展示 | 名称 | 観測上の特徴 |
| --- | --- | --- |
| 01 | VESPER / ヴェスパー | 光を返さない黒曜天体。冷たい青色の輪郭光。 |
| 02 | LACUNA / ラクーナ | 分離した外殻と露出した核。終わらない崩壊。 |
| 03 | ORISON / オリゾン | 氷と金属の巨大な多重環。増え続ける空白。 |
| 04 | GEMINA / ジェミナ | 琥珀色と青白色の二つの恒星による照明。 |
| 05 | VIGIL / ヴィジル | 惑星を包囲する、年代不明の環状人工構造物。 |

名称、直径、観測結果、世界設定はすべて創作です。天体の距離、縮尺、照明、恒星の位置は鑑賞のための演出であり、天体物理シミュレーターではありません。

## 操作

天体そのもの、天体名のラベル、画面下の展示一覧から個別展示を選べます。「惑星系へ」または左上のNOUMENロゴで全体へ戻ります。左右の矢印ボタンでも展示を切り替えられます。

キーボードは `←` / `→` で前後の展示、`Esc` で全体へ戻ります。「本館について」が開いているときは、Esc はそのダイアログだけを閉じます。

スマートフォンでは下部の展示一覧を横にスワイプできます。個別展示の解説領域は縦にスクロールでき、最後の観測記録まで読めます。

「一時停止」は自転やカメラの微小な揺らぎを止めます。展示の選択は停止中も使用できます。「描画」は標準 → 高 → 低の順で切り替わります。スマートフォンでも初期品質は**標準**です。設定や履歴を保存する機能はありません。

端末の `prefers-reduced-motion`（視差効果を減らす）設定が有効な場合、初期状態で動きを停止し、移動演出を省略します。タブが非表示の間は描画を止めます。

```text
├── .nojekyll               # GitHub Pagesの静的配信
├── css/
│   └── main.css            # PC / スマートフォン / 横画面

│   ├── renderer.js         # WebGL、画像読み込み、品質制御
│   └── app.js              # 展示切替・カメラ演出・入力・UI
├── assets/
│   ├── mark.svg            # オリジナルの館章

```

## 描画について

外部ライブラリやCDNを使わず、ブラウザのWebGLとGLSLシェーダーで描画します。球体、複数の断裂した殻、微小な破片、薄い環、厚みのある環状人工構造物に対して、カメラからの光線との交点を計算する3Dレンダラーです。

惑星の自転、表面の凹凸、反射、輪郭の散乱光、核の発光、環の粒子密度や影、二色の照明、構造物のパネルと開口部を独自に表現しています。説明用の完成画像を拡大するだけの実装ではありません。

背景・表面画像はこの作品向けに手続き生成したオリジナル画像です。Webフォント、外部API、アクセス解析、Cookie、ストレージ、音声の自動再生は使用しません。

3Dが利用できない場合は、同じレンダラーから書き出した天体の静止画に切り替えます。展示選択と解説はそのまま利用できます。初回読込には画像の取得とGPUでのシェーダー準備が必要です。

## 編集

解説や名称は `js/catalog.js` を編集してください。`position` / `radius` がPCの俯瞰配置、`mobilePosition` / `mobileRadius` がスマートフォンの俯瞰配置です。`camera` は個別展示の距離・寄せ方を定義します。

色や文字、余白は `css/main.css`、3Dの素材と形状は `js/shaders.js`、カメラ移動時間は `js/app.js` の `navigate()` にあります。

## テスト

```powershell
node --test
```

Node.js の組み込みテストランナーのみを使います。テストはデータの整合性・数学関数・ファイル構成の検証です。実際のブラウザやGPUの見た目まで保証するものではありません。実施したブラウザ確認の範囲は `VERIFICATION.md` に記載しています。

## チャット用プレビューとの関係

別添の `NOUMEN-preview.html` は、チャットで受け渡しやすくするため、同じソースと画像を1ファイルにまとめたプレビュー専用版です。このプロジェクト本体は分割構成で、プレビュー専用HTMLに依存しません。GitHub Pages にはこのフォルダ一式を公開してください。
