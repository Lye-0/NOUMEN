# NOUMEN — 深宙観測博物館

**未知は、静かに存在する。**

五つの架空の天体を、宇宙から静かに鑑賞する3D展示です。惑星系の俯瞰から個別展示へ近づき、姿と不可解な観測記録を眺めます。

**バージョン 1.2.0 — 全天体の質感改良を統合した公開用プロジェクト。** VESPER / ORISON / VIGILの新しい描画に加え、前回のLACUNA / GEMINAの改良も含んでいます。追加の差分ファイルや旧版ZIPは必要ありません。

## GitHub Pagesで公開する

1. この `noumen` フォルダの**中身**を、リポジトリのルートに配置します。`index.html` が直下に来るようにしてください。
2. GitHub の **Settings → Pages → Build and deployment → Source** で **Deploy from a branch** を選びます。
3. **Branch: main / Folder: / (root)** を選び、Save を押します。既定ブランチがmain以外なら、そのブランチを指定してください。

ビルド、`npm install`、APIキー、環境変数は不要です。HTML・CSS・JavaScriptと同梱画像のみで動くため、独自の `.github/workflows` は含めていません。空ファイルの `.nojekyll` はそのまま残してください。

公開用のコードは相対パスを使っています。ドメイン直下だけでなく、`https://ユーザー名.github.io/リポジトリ名/` のようなサブディレクトリにも配置できます。

GitHub公式の設定手順：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ローカルで確認する

Node.jsがある場合、このフォルダで次を実行します。追加パッケージは不要です。付属ツール・テストの動作確認環境はNode.js 22です。

```powershell
node tools/serve.cjs
```

ブラウザで `http://127.0.0.1:8000` を開きます。8000番が使用中なら、`node tools/serve.cjs 8001` で変更できます。終了はCtrl+Cです。付属サーバーはローカル確認用であり、インターネットへ直接公開する本番サーバーではありません。

`index.html` のダブルクリックによる `file://` では、ブラウザのローカル画像保護によって3D用テクスチャを読み込めない場合があります。その場合は静止画展示になります。分割版の3D表示にはHTTPサーバーを使ってください。

## 今回の改良

| 天体 | 描画上の変更 |
| --- | --- |
| **VESPER** | 暗い黒曜質の表面、細い断裂と凹凸、粗さの変化を追加。浅い角度の光だけを反射し、夜側を深い黒に沈めます。広い青色の発光を抑え、縁にだけごく弱い異常光を残しています。 |
| **ORISON** | わずかに扁平なガス惑星。環と自転軸を揃えた大気の帯、渦、淡い雲を追加。環には不規則な密度差と隙間、氷・塵を思わせる色の差、角度に応じた透過、惑星と環の相互の影を付けています。 |
| **VIGIL** | 環状構造物を実メッシュで再構築。厚みのある外装、縁、放熱板、区画、開口部、疎らな灯火を追加。金属・断熱材の反射を描き分け、構造物同士と惑星に落ちる影を描画します。地表は氷殻の濃淡・細い断裂・クレーターを持つ表面です。 |
| **LACUNA** | 前回の改良を継承。不規則に分離した岩盤、厚みのある破断面、露出した発光核、角張った破片。単純な球の輪切りではありません。 |
| **GEMINA** | 前回の改良を継承。地表・海・雲・大気の描き分け、4Kの地表と雲、海面反射、雲の影と独立した移動、二つの恒星による照明。 |

VESPER / ORISON / VIGILの素材には新しい4096×4096の共通画像を使用します。これは複数の2048×1024の素材領域をまとめたアトラスであり、各天体が独立した4Kテクスチャを持つわけではありません。GEMINAとLACUNAの既存素材はそのまま継承しています。

俯瞰・五つの個別展示の静止画も、PC用・スマートフォン用の**計12枚をこの版のレンダラーから再出力**しています。WebGL非対応時にも古い惑星へ戻りません。

## 操作

天体そのもの、天体名のラベル、画面下の展示一覧から個別展示を選びます。「惑星系へ」または左上のNOUMENロゴで全体へ戻ります。左右の矢印ボタンでも展示を切り替えられます。

キーボードは `←` / `→` で前後の展示、`Esc` で全体へ戻ります。「本館について」の表示中は、Escはそのダイアログだけを閉じます。

スマートフォンでは下部の展示一覧を横にスワイプできます。個別展示の解説領域は縦にスクロールでき、最後の観測記録まで読めます。VESPERは小さい縦画面でも反射する縁が見えるよう、専用の撮影距離にしています。

「一時停止」は自転やカメラの微小な揺らぎを止めます。停止中も展示を選べます。「描画」は**標準 → 高 → 低**の順で切り替わります。スマートフォンでも初期品質は標準です。設定や学習履歴を保存する機能はありません。

`prefers-reduced-motion`が有効な場合、初期状態で動きを停止し、カメラ移動の演出を省略します。タブが非表示の間も描画を止めます。

## 描画と負荷

外部ライブラリ、CDN、Webフォント、APIを使わず、WebGL 1とGLSLで描画します。球・扁平球・環の交差計算と、実際の三角形メッシュのラスタライズを組み合わせています。完成した惑星写真を背景に貼るだけの実装ではありません。

VIGILの構造物には約13.6万三角形と1,428個の追加部材を使用し、主環・副環・外装をまとめて描画します。LACUNAの岩盤・破片は約10.9万三角形です。別の天体の個別展示では、不要な構造物や岩盤の描画を省略します。

高精細素材にはGPUメモリが必要です。スマートフォンの初期読込では大きい素材を最大2048ピクセルへ縮小し、画面解像度と影の解像度を端末・品質設定に応じて制限します。動作が重い端末では「描画：低」または「一時停止」を使ってください。品質の切替は主に描画解像度と影の解像度を変更し、素材の再ダウンロードは行いません。

材質の反射、環の透過・影には物理的な考え方を取り入れていますが、作品として調整した近似表現です。パストレーシングや天体物理シミュレーションではありません。天体の縮尺・距離・照明・恒星の位置も、展示構図のために再構成しています。名称、直径、観測結果、世界設定はすべて創作です。

素材画像は本作向けに制作したものです。アクセス解析、Cookie、ストレージ、音声の自動再生は使用していません。

## 編集とテスト

解説・名称・俯瞰配置・個別構図は `js/catalog.js`、スマートフォンの個別構図は `js/app.js` の `cameraFor()`、文字や余白は `css/main.css` を編集します。LACUNAの形状は `geology.js`、VIGILの形状は `architecture.js` です。

追加パッケージを入れずにテストできます。

```powershell
node --test
```

データ・数学・形状・素材の継承・参照ファイル・付属HTTPサーバーを検証します。GPUの見た目や実機性能を保証するテストではありません。実施したブラウザ確認の範囲は `VERIFICATION.md` を参照してください。

## チャット用プレビュー

別添の `NOUMEN-realism-complete-preview.html` は、この分割プロジェクトと同じソース・画像をまとめた受け渡し用プレビューです。**公開用ZIPは分割構成**であり、プレビューHTMLには依存しません。

同じプレビューを自分で書き出す場合だけ、次の任意のコマンドを使えます。

```powershell
node tools/make-preview.cjs ../NOUMEN-realism-complete-preview.html
```

画像をすべて内包するため、単独プレビューHTMLはZIPより大きくなります。GitHub Pagesには単独版ではなく、この分割プロジェクトを配置してください。
